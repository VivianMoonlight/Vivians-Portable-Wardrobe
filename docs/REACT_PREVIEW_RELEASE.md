# React preview 0.10.1-react.2

发布分支：`feat/wardrobe-react`。加载器及自动更新地址使用编码后的分支名 `feat%2Fwardrobe-react`，避免回到旧预览或稳定分支。

## 本次交付

- 服装索引、多唯一标签、旧文件夹路径迁移、瀑布流、侧栏筛选和手机适配。
- 点击选衣后默认完整替换并进入预览微调，最后应用到指定角色；分组按补入、覆盖、完全替换循环，单部件直接选来源。
- 身形快捷操作为单次修改，原角色的身体、面容和完整头发部位保留原数据；最终应用使用已准备的预览结果。
- 删除墓碑、基于修订号的合并、持久本地待同步状态，以及整个 `Player.ExtensionSettings` 的 180000 字节共享容量显示与超限暂停。
- BC 图片动态就绪驱动的渲染、可见性订阅、缓存和取消；图片失败时提示并支持明确重试。

## 最后审查修复

1. 首次云快照也通过账号校验，拒绝其他账号数据写入当前本机索引。
2. 制作物属性只补入所选衣物来源，不覆盖选择保留的原角色发色或样式。
3. 切换目标角色时按新角色重新计算仍有效的分组策略，保留逐部件手动选择。
4. 应用后保持当前编辑会话的原角色基准；下一次选衣重新捕获实际外观。
5. 微调分组使用唯一的无障碍标识；窄屏和矮窗口可以滚动访问末尾部位，应用按钮始终可见。
6. 筛选抽屉按层处理 Escape，预览失败提供状态说明与重试。

## 验证与打包

```sh
npm run typecheck
npm test
npm run test:browser
npm run package:react
```

JavaScript 另执行 `node --check` 静态语法检查。浏览器测试使用独立模拟宿主、真实 React 组件和浏览器画布；BC 加载器回归可选择从本地读取固定上游版本。测试不等于真实账号联机验证。

`package:react` 构建并同步 React 加载器版本，将产物写入 `out/`，不会提交、推送或修改稳定版加载器。正式产物关闭 source map；发布前检查当前源码、文档、产物及提交作者/提交者身份，使用 VIV 开头的项目假名和 GitHub noreply 邮箱。

# 快速开始 (Quick Start)

Vivian's Portable Wardrobe (VPW) 是你的 BC 超级衣柜与外观工作台。
本指南带你一分钟速览系统的核心功能与操作逻辑。

## 🧭 四大功能面板

点击屏幕边缘的 **悬浮按钮** 展开主界面，底部可切换四大核心模块：

- 👗 **Wardrobe (衣柜)**：你的私人外观库。管理文件夹、保存当前外观、高级搜索、拖拽排序、一键换装。
- ⏪ **History (历史记录)**：外观“后悔药”。自动记录你最近的换装过程，点错衣服可以随时一键回滚。
- 🎨 **Studio (工作室)**：精调工作台。支持对衣服部件、多层颜色、图层顺序、偏移度进行微调与重组。
- ⚙️ **Settings (设置)**：管家中心。全库数据备份/恢复、BCX 代码导入/导出、云同步额度监控、UI 偏好设置。

## ⚡ 核心能力速查手册

### 1. 像管理电脑文件一样管理衣服
- **无限层级文件夹**：支持新建嵌套文件夹，把日常、晚礼服、Cosplay 衣服分门别类。
- **直觉式操作**：支持拖拽移动文件，支持名称、创建时间排序，支持列表/缩略图双视图切换。
- **全局搜索**：忘了衣服放在哪？直接使用搜索框全局穿透查找。

### 2. 所见即所得的“试衣间”
- **悬停预览 (Hover Preview)**：鼠标停留在列表的衣服上，角色的外观会**实时发生变化**。不满意直接移开鼠标，无需真实换上。
- **局部换装策略 (Filter)**：不仅能全身替换，还能智能混搭：
  - *添加到空槽位*：只穿身上没有的部位。
  - *合并并替换*：将新衣服穿上，并挤掉冲突的旧部件（保留不冲突的部分）。
  - *完全替换*：脱掉全身，换上目标套装。

### 3. 不怕手滑的“时光机”
- **自动记录**：每次外观发生变化，系统会在后台悄悄拍一张照片（快照）。
- **一键回滚**：不小心脱错了一件极其复杂的锁具或衣服？打开 History 面板，点击列表中上一个状态，**立刻无损复原**。

### 4. 彻底告别“丢档焦虑”
- **双轨存储**：所有衣服默认保存在本地（浏览器缓存层），**容量无上限**。
- **云同步 (Cloud Sync)**：你可以单独为某个重要的文件夹打上“云标志”。带云标志的衣服会跟随你的 BC 账号同步，换电脑也能看到（注意：云端总容量约为 180MB [待确认: 实际配额取决于BC限制, 约180KB-MB]，超载会红名告警）。
- **BCX 分享与全库导出**：一键拷贝单套衣服的 **BCX 代码** 发给朋友；或导出 **ZIP/JSON 包** 把整个衣柜备份到电脑硬盘。

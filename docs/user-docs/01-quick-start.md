# 快速开始

Vivian's Portable Wardrobe（VPW）用索引和多标签管理 BC 衣物。点击屏幕边缘的悬浮按钮，可在「衣橱、历史、设置」间切换。

## 找衣物 → 试穿预览 → 应用

1. 在衣橱搜索衣物或标签。桌面使用旁侧筛选栏，手机点击「筛选」。用「卡牌」看瀑布流缩略图，或用不带缩略图的「列表」浏览名称。
2. 点击衣物打开试穿预览。桌面在右侧预览，手机切换到预览页面。每次选择都默认完全替换，只改变预览。
3. 如需调整，点击「微调部位」。桌面打开弹窗，手机进入微调页面。可以按组调整、逐部位选择来源，或使用身形快捷操作。
4. 点击「完成微调」返回预览；手机也可点「返回预览」。这一步保留调整，不会给角色换装。
5. 确认目标角色和外观，点击「应用到『角色名』」。桌面可继续点选其他衣物；手机点击「返回衣橱」继续浏览。返回会保留搜索、筛选和浏览位置。

选衣不会直接应用，实际换装仍受游戏权限、锁具及资产可用性限制。

## 快速微调

- 分组按钮显示当前需要的下一步：缺部位时「补入」，已补齐时「覆盖」，内容已一致时「完全替换」。完成后保持结果。
- 单个部件的滑块直接选择「原角色、所选衣物、置空」。
- 「保留原身形」恢复原角色的身体、面容、发型和发色，其他选择保留。
- 「只替换身形」使用所选衣物的这些部位，其余部位恢复原角色。

这些操作只修改本次预览。下次选衣仍从新衣物的完全替换开始。

## 保存与标签

在「导入 / 导出 → 保存当前穿着」输入衣物名称。通过「管理标签 → 新建标签」创建不重复的标签，再用衣物的「更多操作 → 编辑标签」添加一个或多个标签。

删除标签不会删除衣物。旧文件夹首次升级后转换成完整路径标签，例如 `日常 / 夏季`。

## 本机、云端与备份

衣物先保存到浏览器本地存储。容量区分别显示本机保存结果和云端进度；每件衣物可切换「参与云同步 / 仅保存在本机」。所有扩展共享 **180000 字节（180 kB）**，超限会暂停上传。

「已提交（默认成功）」表示衣橱已调用 BC 的提交接口；BC 不会逐次回执。下次完整登录回读用于发现差异或冲突。换设备前，在「导入 / 导出 → 保存备份」下载 JSON，并在新设备确认衣物可用。

# 快速开始

Vivian's Portable Wardrobe（VPW）用索引和多标签管理 BC 服装。打开屏幕边缘的悬浮按钮后，可以在“衣柜、历史、设置”间切换。

## 找衣服 → 预览与微调 → 应用

1. 在衣柜搜索服装名或标签名。桌面使用旁侧筛选列表；手机点击“筛选”打开抽屉。可筛选标签及云同步范围，服装缩略图以瀑布流排列。
2. 点击一张服装卡片，直接进入“预览与微调”。每次选择都会先完整使用所选衣物组成预览；选衣本身不会换装。
3. 在角色预览旁调整分组来源，或用单个部件的滑块选择“原角色、所选衣物、置空”。
4. 确认目标角色和最终外观后，点击末尾唯一的“应用到「角色名」”按钮。
5. 想继续找衣服时点击“返回衣橱”，搜索和标签条件会保留。重新选衣会重新从该服装的完整外观开始。

卡片使用点击选择；悬停和双击都不会直接应用服装。预览使用 BC 的角色绘制能力，实际应用仍受游戏权限、锁具及资产可用性约束。

## 快速微调

- 分组的“原角色 / 所选衣物”来源按钮按“补入 → 覆盖 → 完全替换”循环，再点一次回到补入。
- 单个部件的滑块直接选择来源或空，不参与分组的三步循环。
- “保留原身形”一次性恢复原角色的身体、面容和完整头发槽；“只替换身形”使用所选衣物的这些部位，其余部位保持原角色。
- 身形快捷操作包含发型与发色，可在当前预览中继续微调；下次选衣仍从完整所选衣物开始。

## 保存与标签

在“导入 / 导出 → 保存当前穿着”输入服装名称。点击“管理标签 → 新建标签”创建全局不重复的标签，再通过服装“更多操作 → 编辑标签”分配一个或多个标签。

删除标签不会删除服装。旧目录首次升级后转换成完整路径标签，例如 `日常 / 夏季`。

## 本机、云端与备份

服装先写入容量有限的浏览器本地存储。衣柜容量区分别显示本机保存结果和云端进度；每套服装可以切换“参与云同步 / 仅保存在本机”。

共享扩展设置预算为 **180000 字节（180 kB）**，超限会暂停上传。“已提交，等待核验”与“云端回读已核验”不同；换设备前先用“导入 / 导出 → 保存备份”下载 JSON，并在新设备确认数据。

历史记录用于查阅近期外观，长期保存仍应存入衣柜。设置页提供当前界面主题选项。

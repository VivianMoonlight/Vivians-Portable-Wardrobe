# 📱 主题、语言与移动端 (Theme / Language / Mobile)

本章为你快速解答三个基础环境问题：界面长什么样、界面写什么字、在手机上能不能用。

## 🎯 到底能干什么？

- **护眼与美化**：半夜查衣柜太亮？一键切换黑暗模式。或者你是“Themed BC”的忠实用户，想要完美的沉浸式融合。
- **弄懂语言机制**：想知道为什么你的界面是中文/英文，以及该怎么改。
- **手机通勤可用性**：出门在外用手机登 BC，想知道能不能呼出衣柜换衣服。

## ⚡ 环境设定速查手册

### 1) 🎨 主题切换 (Theme)
如果你觉得白底太亮，或者黑底太闷：
1. 打开 VPW 主面板，点击右侧的 `Settings`（齿轮）标签。
2. 找到 `Theme Settings` 区域，这里有三个选项：
   - ☀️ **Light mode**（浅色模式）：默认白底。
   - 🌙 **Dark mode**（黑暗模式）：纯正黑底，熬夜护眼。
   - 🎭 **Themed mode**（跟随外部主题）：如果你安装并开启了 `Themed BC` 插件，选这个！VPW 会自动吸取并使用该插件的颜色体系，达到完美的 UI 统一。
3. 点完立刻生效，而且会**永久记住**你的选择（存在本地浏览器）。

### 2) 🌐 语言机制 (Language)
VPW 到底怎么决定对你说什么语言？
1. **全自动匹配**：VPW 目前内置了 `en`（英文）和 `zh`（简体中文）。
2. **看浏览器脸色**：启动时，它会偷偷看一眼你的浏览器首选语言。如果是 `zh-CN` 或带 `zh` 的，就给你看中文；其余一律给你看英文以保平安。
> 💡 提示: 目前**没有**提供一个可以点来点去的“语言切换按钮”。你想换语言？去改你浏览器的语言设置，然后按 F5 刷新。

### 3) 📱 移动端边界 (Mobile)
你在手机上（或把电脑浏览器窗口极度拉窄）打开 VPW：
1. 界面会自动变成**移动端专属布局**，依然可以通过悬浮小按钮唤出。
2. 移动端拥有三个粗壮的底部主标签：`Wardrobe`（衣柜）、`History`（历史卷轴）、`Settings`（设置）。
3. 空间有限，左中右面板被折叠成了三个顶部子标签栏开关：`Preview`（看小人）、`List`（看列表）、`Filter`（搜关键字）。
4. **⚠️ 绝对禁区**：你在手机上**找不到 `Studio`**（工作室）！
   - 因为 Studio 这种像开战斗机一样密密麻麻的面板，在手机上根本没法点。
   - 手机端的使命是：**看衣柜、读取保存套装、把衣服穿到身上**。捏衣服的重活请回电脑前干。
   - 如果你在电脑上开着 Studio 突然把窗口拉细，系统会为了安全强制把你踢回 `Wardrobe` 标签。

## 🚑 环境急救箱

### 1. 🎭 我切了 Themed 模式，但界面变得极其违和/毫无变化
**检查**：你到底有没有装并开启 `Themed BC` 插件？
**恢复**：如果没装，VPW 吸不到颜色就会回退（或者变得奇怪）。请去 `Settings` 老老实实切回 `Dark` 模式保平安。

### 2. 🌐 我是中国人，但它死活对我说英文
**检查**：你的浏览器/手机系统语言是不是被设成了 English？
**恢复**：去浏览器的设置里，把“语言”项的“简体中文”拖到最上面第一顺位，刷新页面，VPW 就会乖乖说中文了。

### 3. 📱 手机上怎么都找不到捏衣服（Studio）的入口
**检查**：这是特色，不是 Bug。
**恢复**：放弃在手机上搞高定风的幻想。手机上只适合做“一键换装”和“保存当前穿搭”，复杂的调色和图层重排请打开电脑。

# 主题、语言与移动端

本章对应当前 React 版。桌面和移动端都提供“衣柜、历史、设置”；旧版 Studio 和 Themed BC 主题接入尚未提供当前入口。

## 主题

在“设置 → 主题设置”选择“浅色模式”或“深色模式”，立即生效。桌面工具栏的太阳/月亮按钮也可以切换主题。

主题选择保存在本浏览器；默认浅色。清理站点存储或换浏览器后，偏好可能需要重新设置。当前没有第三个 Themed 模式选项，安装外部主题插件也不会自动接入其颜色。

## 语言

当前支持简体中文 `zh` 和英文 `en`，启动时依次采用已保存的有效语言偏好、浏览器主语言标记，其他情况使用英文。例如 `zh-CN` 使用中文。

当前设置页没有语言切换按钮。没有已保存偏好时，调整浏览器首选语言并刷新即可；已有偏好会优先于浏览器语言。

需要手动改已有偏好时，可在浏览器开发者工具的本站点本地存储中，将 `locale` 改成 `zh` 或 `en`，然后刷新。只修改这一项，不要清空整站存储来切换语言。

## 桌面与手机的同一流程

衣柜先显示搜索、筛选和瀑布流服装列表。桌面将标签及云同步范围放在旁侧筛选栏；手机点击“筛选”打开抽屉，选择条件后继续浏览。

点击服装直接进入“预览与微调”：每次先完整预览所选衣物，再调整组来源、单部件或身形快捷操作。手机和桌面都通过末尾的“应用到「角色名」”完成换装；悬停或双击卡片不会直接应用。

“返回衣橱”保留搜索和标签条件。身形快捷操作包含身体、面容和完整头发槽，发型与发色一起处理；分组循环与单部件选择的规则见 [核心工作流](02-core-workflows.md)。

## 窄屏布局

页面视口宽度小于 900 像素时，衣橱采用全屏布局；判断依据是浏览器视口，不是桌面衣橱浮窗自身的宽度。

- 标题下方切换“衣柜、历史、设置”。
- 衣柜的浏览和微调是连续步骤，不需要在旧“预览 / 列表 / 过滤”三面板之间来回切换。
- 服装搜索和标签筛选用于查找；微调中的分组及部件控件用于组合外观。
- 移动全屏面板通过标题旁的关闭按钮收起；桌面宽视口使用可拖动、缩放的浮窗。

当前两个布局都没有 Studio 入口，旧说明见 [文档总览的旧版归档](00-index.md#旧版归档)。保存或同步异常见 [故障排查](08-troubleshooting-faq.md)。

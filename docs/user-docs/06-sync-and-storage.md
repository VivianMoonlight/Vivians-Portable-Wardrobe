# 云同步与容量

衣橱会先把修改保存到本机，再尝试同步到 BC 账号。衣橱容量区可以分别查看本机保存结果、云端进度和共享容量，并可“重试上传”；展开详情可查看剩余空间及可用的迁移备份导出。

## 先看同步状态

| 界面提示 | 表示什么 |
| --- | --- |
| 已保存到本机 | 当前修改已写入这个浏览器的本地存储 |
| 等待上传 | 修改已保存，等待提交 |
| 已提交，等待核验 | 已调用游戏提交接口，尚未通过新鲜云端数据核对 |
| 云端回读已核验 | 最近登录或重连返回的数据与待同步内容相符 |
| 离线、容量超限或同步需要处理 | 上传未完成，按提示恢复连接、减少同步内容或重试 |

“已提交”不代表服务端已确认保存。点击“重试上传”可重新尝试提交，不会主动读取云端；核验依赖登录、重连时返回的新数据。不要只看到提交状态就清理原设备数据。

## 选择哪些服装参与同步

在服装卡片上点击“参与云同步”或“仅保存在本机”，即可切换这件服装的同步开关。

- **关闭**：保留本机服装，后续上传不再包含其服装内容。其他设备已经保存的本机副本不会自动擦除。
- **重新开启**：从仍保留服装的设备点击开关，将这件服装重新加入同步。
- **删除服装**：与关闭同步不同，会记录删除，并在副本交换数据时传播。

服装开关独立于标签；改标签不会自动改变同步范围。标签名称及少量同步元数据仍会上传，因此“仅保存在本机”不表示其所有关联标签都隐藏于云端。

## 容量为什么会满

面板按 **180000 字节（180 kB）**检查整个扩展设置，并另行检查上传单包大小。这是所有扩展共享的预算，VPW 能用的空间会受到其他扩展影响。

面板列出 **VPW、其他扩展、总用量、剩余量**，均按 1000 字节换算为 1 kB。用量达到 80% 时提示接近上限；超限时暂停上传，不删除已经保存的本机服装。

可以把不常用或体积较大的服装设为“仅保存在本机”，然后重试。删除标签不能保证明显释放空间；为防止旧设备恢复已删内容，系统还要保留删除记录。

## 用标签整理衣橱

1. 点击“管理标签 → 新建标签”，输入全局不重复的名称。
2. 打开服装的“更多操作 → 编辑标签”，选择一个或多个标签，再点“保存标签”。
3. 在桌面旁侧筛选列表，或手机“筛选”抽屉里选择“全部服装”“未加标签”或某个标签；搜索框同时搜索服装名和标签名。
4. 要改名或删除标签，先在筛选列表选中它，再使用“管理标签”。删除标签不会删除服装。

旧文件夹首次升级后会变成完整路径标签。例如 `日常 / 夏季`，其中的服装同时带有 `日常` 和 `日常 / 夏季`。这只是标签名称，不需要逐层进入文件夹。

## 备份与换设备

本地使用浏览器的 `localStorage`，空间有限；清理站点数据、换浏览器或换设备都会影响可用的本机副本。本地保存失败时先导出备份并处理提示，不要继续依赖未保存的修改。

- 在“导入 / 导出 → 保存备份”导出当前衣橱 JSON，包含本机服装和标签。
- 升级时有旧数据归档，容量区会出现“导出迁移前备份”。请保存这份恢复材料，原始旧数据不会自动重新并入新衣橱。
- “导入 / 导出 → 备份导入”会把备份中的服装作为新副本加入，并复用同名标签；重复导入可能产生重复服装。

换设备前保存一份 JSON 备份，在新设备确认服装可用后再处理旧设备。云同步方便跨设备使用，独立备份方便恢复误删和未同步内容。

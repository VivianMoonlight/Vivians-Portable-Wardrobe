# 云同步与容量 (Sync & Storage)

为什么我的系统会疯狂报警亮红灯？到底什么是“云端”，什么是“本地”？
本章用最直白的方式，教你如何优雅地绕过 BC 平台的存储限制，把几百件衣服塞进你的库里。

## ☁️ 1. 搞懂“双轨制”：你的衣服到底存在哪？

VPW 采取了两套存储方案并行运作：

1. **本地存储 (无限容量)**：你捏的所有衣服、建的所有文件夹，第一时间都会存在你的**浏览器缓存**里。这个空间是**无限的**！只要你不清空浏览器缓存，存一万件衣服也没问题。
2. **云端同步 (约 180KB 极限)**：如果你换了台电脑登录 BC，本地存的衣服就没了，需要从云端拉取。但很坑的是，**BC 原生平台分配给每个账号的云端总空间大约只有 180MB [待确认：或 180KB左右，目前极其受限]**。一旦你强行把所有衣服塞上云，系统就会崩。

## 🚨 2. 红灯警告：“180KB 溢出” 是怎么回事？

当你在设置里发现容量指示条爆红，或者界面提示“同步超载”时，不要慌！

- **我的衣服坏了吗？** **绝对没有！** 你的衣服在本地存得好好的，没有任何数据损坏。
- **那为什么报警？** 因为云端的“微小网盘”已经被你塞满了。为了保护你的存档不被彻底挤爆销毁，系统**强制切断了上传通道**。
- **有什么后果？** 在红灯解除前，你在 A 电脑新捏的衣服，去 B 电脑上登录时可能看不到，因为传不上去。

## 🎯 3. 破局之法：选择性“挂云” (Cloud On/Off)

既然云端容量这么小，我们就不放那些“几年穿不了一次”的衣服了。VPW 提供了**精准指定云同步**的开关。

### 步骤一：关闭冷门衣服的同步 (Cloud Off)
1. 找出你那些“吃灰”的衣服文件夹，比如：`废弃草稿`、`几百年前的Cosplay`、`体积巨大的重型拘束服库`。
2. 右键这个文件夹，找到云朵图标相关的开关，把它设置为 **Cloud Off**。
3. **效果**：这个文件夹里的所有衣服立刻从云端网盘里删掉，腾出宝贵的空间。但请放心，**它们在你的本地（这台电脑上）依然可见可用**！

### 步骤二：开启核心常用衣服的同步 (Cloud On)
1. 建立一个比如叫 `常用穿搭 (Daily)` 的文件夹。
2. 把云开关设置为 **Cloud On**。
3. **效果**：只有这个精锐部队才会占据那 180KB 的云资源。你换电脑登录时，确保能立马穿上最爱的几套。

---

## ⚠️ 4. 终极警告：永远不要把云同步当唯一备份！

不要以为你的衣服挂了“Cloud On”就万事大吉了！
如果你的浏览器缓存被清理程序误删，去网吧打游戏环境不稳，或者 BC 服务器抽风，你的云数据随时可能蒸发。

**真正的防丢档终极方案只有一个**：
👉 **定期去 Wardrobe 里点一下 `Export` 导出 JSON 文件，保存到你的电脑硬盘或网盘里！**

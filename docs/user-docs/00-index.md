# 用户文档总览

本文是用户文档的统一导航入口。整套手册收口为 01-08 八篇，按“先上手、再进阶、后排障”的路径组织。

## 文档地图

1. 01-quick-start.md: 快速开始与能力总览
2. 02-core-workflows.md: 日常衣柜管理与过滤换装
3. 03-studio-basics.md: Studio 基础编辑闭环
4. 04-studio-advanced.md: Studio 高级能力（优先级/批量/调色板/历史/会话）
5. 05-data-backup-import-export.md: 备份、恢复与 BCX 互通
6. 06-sync-and-storage.md: 云同步规则与容量治理
7. 07-theme-language-mobile.md: 主题、语言、移动端边界
8. 08-troubleshooting-faq.md: 症状驱动排障与恢复

## 按目标阅读

1. 首次使用：01 -> 02 -> 05
2. 深度编辑：03 -> 04 -> 06
3. 快速排错：08（必要时回看 02/03）

## 使用说明

1. 每篇文档统一结构：适用场景 -> 操作步骤 -> 结果预期 -> 常见失败与恢复。
2. 文档以功能说明为主，不展开冗长背景教学。
3. 当功能行为与页面不一致时，以当前版本界面实际显示为准。

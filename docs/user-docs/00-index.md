# 用户文档总览

本导航适用于当前 React 版：衣橱使用衣物索引与多标签，主界面提供“衣橱、历史、设置”。

## 当前版本

1. [快速开始](01-quick-start.md)：保存、查找、预览和换装入口。
2. [核心工作流](02-core-workflows.md)：标签整理、搜索筛选、分组操作、部件来源及历史记录。
3. [数据与备份](05-data-backup-import-export.md)：JSON、BCX、玩家衣柜导入及迁移恢复材料。
4. [云同步与容量](06-sync-and-storage.md)：逐件同步开关、本机保存、云端核验及共享容量。
5. [主题、语言与移动端](07-theme-language-mobile.md)：当前浅色/深色主题、语言优先级与窄屏布局。
6. [故障排查](08-troubleshooting-faq.md)：导入、预览、容量和跨设备问题。

首次使用可从“快速开始 → 核心工作流”阅读。换设备前先看“数据与备份”和“云同步与容量”；遇到错误直接查看“故障排查”。

开发者可参考 [衣橱索引与云同步设计](../INDEXED_WARDROBE_SYNC.md)，了解迁移、合并和验证边界。

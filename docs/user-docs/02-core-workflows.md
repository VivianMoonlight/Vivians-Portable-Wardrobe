# 核心工作流

在衣橱找到衣物后，打开试穿预览，按需微调，最后应用到选定角色。

## 保存与整理

1. 在「导入 / 导出」中选择「保存当前穿着」，输入名称。
2. 如已选中一个标签，新衣物会带上该标签。「全部衣物」和「未加标签」不会额外添加标签。
3. 通过「管理标签 → 新建标签」创建名称不重复的标签。
4. 打开衣物的「更多操作 → 编辑标签」，选择一个或多个标签并保存。

衣物菜单也提供重命名、删除和 BCX 导出，桌面可右键打开同一菜单。删除标签只取消分类；删除衣物会同步这次删除。

旧文件夹升级后变成完整路径标签。例如一件衣物可同时带有 `日常` 和 `日常 / 夏季`。一件衣物拥有多个标签仍是同一件衣物。

## 找到衣物

- 主搜索框同时匹配衣物和标签名称。
- 桌面筛选栏提供「全部衣物」「未加标签」、标签列表及云同步范围；标签较多时可先搜索标签。
- 手机点击「筛选」打开相同条件。搜索、标签及云同步范围共同筛选结果。
- 「卡牌」以瀑布流展示缩略图；「列表」只展示名称、标签和操作，不加载缩略图。
- 「清除所有筛选」同时清除搜索、标签和云同步范围限制。

## 选择后立即预览

点击衣物会打开试穿预览。桌面在右侧显示，衣橱仍可浏览；手机进入预览页面，点击「返回衣橱」即可继续找衣物。搜索、筛选和浏览位置会保留。

每次选择都默认完全替换：所有部位先切到「所选衣物」，衣物没有的部位在预览中为空。重新点选也会从完全替换重新开始，之前的微调不会带入新选择。

选衣只修改预览。最后点击「应用到『角色名』」才会换装。

## 微调后返回预览

点击「微调部位」调整分组或单个部件，角色预览会实时更新。桌面使用弹窗，手机切换到独立微调页面。

「完成微调」保留当前调整并返回预览。手机的「返回预览」和桌面弹窗的关闭按钮也保留调整。确认效果后，再使用预览中的应用按钮。

## 分组来源：按当前预览决定下一步

每组可以选择「原角色」或「所选衣物」作为来源。按钮显示下一步会做什么：

| 当前情况 | 按钮操作 | 结果 |
| --- | --- | --- |
| 来源包含的部位还有空位 | 补入 | 只填入这些空位，保留已有部件 |
| 这些部位已有内容，但与来源不同 | 覆盖 | 替换来源包含的部位，其他部位保持当前选择 |
| 这些部位已与来源一致 | 完全替换 | 整组使用此来源，同时清空来源没有的部位 |
| 整组已经完全替换 | 已完全替换 | 保持结果，按钮不再可点 |

按钮按实际内容判断，包括颜色和属性，而非计算点击次数。若当前已补齐，第一次点击也可能直接覆盖；若已一致，则直接完全替换。手动改动部件后，下一步会重新判断。

## 单个部件：直接选择

滑块直接选择「原角色」「所选衣物」或「置空」，不会逐步补入或覆盖。

完全替换后，来源没有的部件会清空，但滑块仍显示该来源。只有手动选择「置空」才会切到空档。

组操作基于当前预览：补入保留已有部件，覆盖只改来源提供的部位，完全替换会重新指定整组来源。调整后以预览确认结果。

## 一次性的身形快捷操作

「身形」包括身体、面容及完整头发部位，发型与发色一起处理。

- **保留原身形**：这些部位恢复原角色，其他部位保持当前选择。
- **只替换身形**：这些部位使用所选衣物，其他部位全部恢复原角色。

快捷操作只修改本次预览，之后可以继续微调。下一次选衣仍默认完全替换。

## 应用与保留结果

核对目标角色和预览，点击「应用到『角色名』」。实际换装仍受角色权限、锁具和可用资产限制。

历史记录用于查阅近期外观，数量有限，也不包含在衣橱 JSON 备份内。需要长期保留的结果，应在应用后使用「保存当前穿着」。保存或导入后，分别查看本机保存结果和云端状态。

详见 [云同步与容量](06-sync-and-storage.md)及[数据与备份](05-data-backup-import-export.md)。

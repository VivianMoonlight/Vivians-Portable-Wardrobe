# 核心工作流

当前 React 版将找衣服和试衣分成两步：先在衣橱选择，再进入预览与微调，最后明确应用到目标角色。

## 保存与整理

1. 在衣柜“导入 / 导出”菜单选择“保存当前穿着”，输入名称。
2. 如已选中一个标签，新服装会带上该标签；“全部服装”和“未加标签”不会额外添加标签。
3. 点击“管理标签 → 新建标签”，输入非空、全局不重复的名称。
4. 打开服装“更多操作 → 编辑标签”，选择一个或多个标签并保存。

服装菜单也提供重命名、删除和 BCX 导出；桌面可右键打开同一菜单。删除标签只取消分类，删除服装会写入同步删除记录。

旧文件夹升级后变成完整路径标签。例如一件服装可同时带有 `日常` 和 `日常 / 夏季`；标签是分类，不改变服装的稳定身份。

## 找到服装

- 主搜索框同时匹配服装名称和标签名称。
- 桌面旁侧显示“全部服装”“未加标签”、标签列表及云同步范围；标签较多时可先查找标签。
- 手机点击“筛选”打开抽屉，使用相同条件。搜索、标签及云同步范围共同筛选结果。
- 缩略图以瀑布流排列，可以选择大图、小图或列表视图。
- “清除搜索与标签筛选”可返回完整范围。

## 选择后立即预览

点击服装卡片进入“预览与微调”。每次选择都把各个可控槽位切到“所选衣物”：衣物有的部位使用它，衣物没有的部位在组合结果中为空。

此时只改变预览。卡片没有悬停试穿、点击锁定或双击直接应用行为；真正换装集中在末尾的“应用到「角色名」”。

“返回衣橱”保留当前搜索和筛选条件。重新点选服装会重新初始化完整衣物预览，方便从明确的起点开始调整。

## 分组来源：三步循环

每组可以选择“原角色”或“所选衣物”作为来源。连续点击同一来源按钮，按下表循环；切换到另一来源时从“补入”开始。

| 点击阶段 | 该组如何组合 |
| --- | --- |
| 补入（Add） | 保留基准已有部位，只用所选来源填补空位 |
| 覆盖（Replace） | 覆盖来源包含的部位，来源缺少的部位保留基准 |
| 完全替换 | 整组使用该来源，来源缺少的部位为空 |
| 再次点击 | 回到补入 |

基准是另一份来源：点“所选衣物”时以原角色为基准；点“原角色”时以所选衣物为基准。每次都按这两份来源重新计算该组，第四次补入会恢复与第一次相同的组合规则，不依赖上次完全替换后剩下什么。

## 单个部件：直接选择

部件滑块只有三个直接选择：“原角色”“所选衣物”“置空”。它不执行补入、覆盖、完全替换循环。

滑块表示选择的来源。比如组内完全替换为所选衣物后，某槽位因衣物没有对应部件而实际为空，滑块仍显示“所选衣物”。只有明确选择清空时才显示“置空”，这样可以区分“来源没有部件”和“主动清空”。

组操作会重新计算该组；手动调整部件后，再次进行组操作会按组规则覆盖相关部件选择。调整后以预览确认最终结果。

## 一次性的身形快捷操作

“身形”包括身体、面容及完整头发槽；头发按槽位一起处理，保留原头发时包含原发型和发色。

- **保留原身形**：将这些部位切回原角色，其余部位保持当前选择。
- **只替换身形**：这些部位使用所选衣物，其余部位全部使用原角色。

快捷操作只修改当前预览，可继续通过组按钮和部件滑块调整。下一次选衣仍先完整使用新选服装。

## 最后应用

核对预览中的目标角色，点击末尾唯一的“应用到「角色名」”。此前的选择、分组循环、身形快捷操作和单部件调整都只修改候选外观。

预览沿用 BC 的角色绘制能力；实际换装仍受角色权限、锁具和可用资产限制。历史记录可查阅近期外观，数量有限，也不包含在衣橱 JSON 备份内。需要长期保留的结果，应应用后回衣柜使用“保存当前穿着”。

保存及导入后查看本机保存结果和独立的云端状态。详见 [云同步与容量](06-sync-and-storage.md)及[数据与备份](05-data-backup-import-export.md)。

# 核心工作流 (Core Workflows)

本章介绍衣服的日常管理、高级换装模式（Filter）以及时光机（History）的具体用法。

## 1. 像管理电脑文件一样管理衣服

随着衣服越存越多，乱糟糟的列表会让你抓狂。VPW 提供了一套直觉式的文件管理系统。

- **新建文件夹**：点击衣柜顶部的 `新建文件夹` 图标。建议按场景分类，例如：`日常`、`晚礼服`、`Cosplay`、`特定角色`。
- **拖拽移动**：不需要复杂的选中操作，**按住衣服或文件夹，直接拖拽**到目标文件夹，或者拖到顶部的路径导航栏（面包屑）上，即可完成移动。
- **重命名**：系统默认用时间戳给衣服命名。右键衣服，选择 `Rename`，给它起个好记的名字。

## 2. 找不到衣服？一键穿透搜索

衣服太多找不到？别一页页翻了。

- **当前目录 vs 全局搜索**：
  - `Current`：只在当前打开的文件夹里找。
  - `Global`：**穿透所有子文件夹**，翻遍整个衣柜找这件衣服。
- **排序方式**：点击排序菜单，选择 `Recent`，最近刚穿过、刚修改过的衣服会排在最前面。
- **列表视图 (List)**：如果你需要看长名字，点击视图切换按钮，换成列表模式。

## 3. 高级试衣间：不再“脱光重穿” (Filter 模式)

以前换衣服，总是会把你精心捏好的发型和五官一起覆盖掉？VPW 的 **过滤面板 (Filter)** 彻底解决了这个问题。

点击任意衣服上的 `Filter` 按钮（漏斗图标），你会看到强大的替换策略：

### 粗筛规则 (Apply Mode)
在戴上衣服前，先定个大基调：
1. **添加到空槽位 (Add to empty slots)**：绝对安全模式。只穿你现在没穿的部位。你身上的衣服、头发、锁具**全部保留**。
2. **增量合并 (Add and replace)**：智能覆盖模式。穿上新衣服，只有和新衣服**位置冲突**的地方会被替换，其他不冲突的部位保留。
3. **完全替换 (Full replace)**：无脑覆盖模式。脱光你现在的全身，100% 变成这套新衣服的样子。

### 精细部位控制 (Slot Rules)
如果大基调还不够，你还可以精确到“只要这双鞋，其他全不要”：
- **Incoming (强制穿上)**：不管怎样，我就是要穿上目标衣服的这个部位。
- **Original (强制保留)**：不管怎样，我自己身上的这个部位绝对不能被换掉（比如：锁定我的发型）。
- **Empty (强制脱下)**：穿这套衣服的时候，这个部位必须脱光。
- **Auto (跟随大基调)**：默认状态，由上面的 `Apply Mode` 决定。

> 💡 **最佳姿势**：设置好规则后，**把鼠标停在衣服上不要点**，右侧的角色会实时预览最终效果。确认完美后，再点击 `Apply` 真正穿上！

## 4. 吃后悔药：History 历史回滚

换衣服换到一半崩溃了？不知道自己脱了什么不该脱的部位？

- **自动存档**：只要你穿上、脱下任何部位，系统就会在后台默默保存一个“快照”。
- **如何回滚**：切换到底部的 **History (历史)** 面板。
- **一键恢复**：这里就像浏览器的测览历史。鼠标放上去可以预览当时的样子，点击 `Apply`，**立刻时光倒流**，恢复成那个快照的状态。

> ⚠️ 注意：History 面板只保存最近的一批临时历史。如果你搭配出了一套非常满意的外观，请务必回到 Wardrobe，点击保存按钮永久保存下来。

# 数据与备份 (Data & Backup)

换电脑了？要把辛辛苦苦捏的衣服发给朋友？不小心删错了文件夹想恢复？
本章带你掌握 VPW 的导入、导出与转移功能，彻底告别丢档焦虑。

## 📦 1. 搬家与容灾：全库 JSON 备份

这是最安全的“兜底”操作，建议在整理文件夹、大批量删除代码前，或者准备换浏览器、换电脑时执行。

### 导出整个衣柜 (Export)
1. 打开 Wardrobe 面板。
2. 点击上方工具栏的 **导出 (Export)** 按钮（通常是一个向外的箭头）。
3. 浏览器会自动下载一个 `.json` 文件（例如：`fm-backup_202X...json`）。
> 💡 **建议**：把这个文件存到你的云盘或者另一台电脑上，这是你整个衣柜的“身家性命”。

### 恢复整个衣柜 (Import)
1. 点击 Wardrobe 面板上方的 **导入 (Import)** 按钮。
2. 选择你之前导出的 `.json` 文件。
3. **合并机制**：不用担心导入会清空你现有的衣服！系统默认采用**合并 (Merge)** 策略。它会把备份包里的衣服和文件夹，**追加**到你现在的衣柜里，不会破坏现有结构。

## 🔗 2. 单件分享：BCX 代码导出/导入

想把刚刚捏好的一套“女仆装”发在 Discord 或分享给朋友？使用 BCX 机制，只需复制粘贴一串代码。

### 导出单件衣服 (Export as BCX)
1. 在 Wardrobe 列表中找到你要分享的衣服。
2. **右键**它，选择 `Export as BCX`。
3. **注意**：这时候**不会**下载文件。系统会显示“复制成功”，代码已经悄悄存到你的**剪贴板**里了。
4. 打开聊天软件，直接 `Ctrl+V` (或 `Cmd+V`) 粘贴发送给朋友。

### 导入朋友发来的衣服 (Import BCX)
1. 复制朋友发给你的、或者从论坛找来的那一大串 BCX 代码。
2. 点击 Wardrobe 面板顶部的 **Import BCX** 按钮。
3. 在弹出的输入框里，`Ctrl+V` 粘贴这串代码，点击确认。
4. 叮！这套衣服就神奇地出现在你当前打开的文件夹里了。

---

## 🚚 3. 萌新报到：从原版衣柜一键搬家

如果你是第一次使用 VPW，不需要手动把你原本在 Bondage Club 原生衣柜里的衣服一套套重新存！

1. 找到面板里的 **Import from Player Wardrobe**（从原版衣柜导入）按钮并点击。
2. 系统会自动拉取你原版衣柜里的所有衣服。
3. 你会看到工作区多出了一个带有**今天日期/时间戳的新文件夹**。
4. 点进去，你原来的所有衣服都在里面安然无恙！

> 💡 **安全提示**：这个操作完全独立，**不会**弄乱你的原版衣柜，也**不会**覆盖 VPW 里已有的数据。你可以慢慢把它们拖拽分类到新的文件夹里。

---

## 🛡️ 4. 进阶安全指南 (选读)

- **防污染小技巧**：如果你一口气下载了别人分享的几十套衣服，或者一个巨大的 JSON 备份包。建议先在衣柜里新建一个叫做“**测试区**”的文件夹，在这个空文件夹里执行导入。确认没问题、没病毒、没畸形衣服后，再把它们拖拽合并到你的主力文件夹里。
- **狡兔三窟**：最完美的备份策略是：每个月导出一份 JSON，一份留在电脑 D 盘，一份丢进 Google Drive/百度网盘。只要你的网盘账号在，哪怕电脑炸了，几秒钟就能满血复活。

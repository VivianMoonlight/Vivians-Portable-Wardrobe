# Studio 高级 (Studio Advanced)

本章只讲 Studio 的高级能力：图层优先级重排、多选批量编辑、标签调色板、历史时间线回跳、会话保存管理。

## 适用场景

- 你要处理复杂服装：多层叠加、前后遮挡关系复杂。
- 你要一次改很多层：统一降透明、整体抬高优先级、批量调偏移。
- 你要把一套配色沉淀成可复用标签，并在后续快速套用。
- 你要在多轮实验之间反复对比，随时回滚到某个历史状态。

## 功能速查

| 你要做什么 | 在哪里 | 关键动作 |
|---|---|---|
| 调整图层前后关系 | 右侧工具坞 `Layers` | 拖拽图层/组到目标位置 |
| 一次改多个图层 | `Part Inspector` 切 `Multi` | `Batch Edit` + `=` / `±` |
| 批量改颜色 | `Batch Edit -> Color` | 打开调色板后应用到选中层 |
| 建立颜色标签体系 | 右侧工具坞 `Palette` | `Saved`、`Tag`、重命名/删除 |
| 做标签偏色与转换 | `Palette -> Advanced` | 选基准 Tag，调 `H/L/S` 偏移 |
| 回到任意历史点 | `History` 面板 | 点击时间线状态点跳转 |
| 管理 Studio 会话 | `Saves Manager` | `Save Current` / `Load` / `Rename` / `Delete` |

## 操作步骤

### 1) 用 Layers 面板处理复杂遮挡

1. 在 Studio 顶栏打开 `Layers`。
2. 在图层列表里拖拽单层，或拖拽同优先级分组。
3. 观察目标项顶部/中部/底部高亮，松手完成重排。

结果：图层 `Priority` 会按拖放位置重算，遮挡关系立刻更新。

说明：被锁定层不可拖拽；同部件同优先级会自动折叠为组，便于整体移动。

### 2) 用 Multi + Batch Edit 做批量修改

1. 在 `Part Inspector` 切换到 `Multi`。
2. 选中多个图层后，进入 `Batch Edit`。
3. 选择属性并应用：
   - `Opacity`：统一透明度。
   - `Offset`：统一位移，可启用可视化移动。
   - `Priority`：整体上调/下调层级。
   - `Color`：跳转调色板给选中层上色。
4. 选择模式：
   - `=` 绝对值：直接设置目标值。
   - `±` 相对值：在原值基础上增减。

常用快捷键（多选时）：

- `Ctrl/Cmd + A`：全选当前可选图层。
- `Ctrl/Cmd + D`：清空当前选择。
- `Esc`：先清空选择；无选择时退出多选模式。

### 3) 用 Palette 建可复用配色库

1. 在工具坞打开 `Palette`。
2. 用色盘选色后，可执行：
   - 存到 `Saved` 作为快速色。
   - 创建 `Tag` 作为命名颜色资产。
3. 在 Tag 列表中可直接重命名、删除、查看使用次数。
4. 点击 Tag 色块可把该标签颜色应用到当前目标。

高级用法（Advanced 区域）：

1. 选择一个 `Base Tag` 作为基色。
2. 调整 `H/L/S` 偏移，生成偏色方案。
3. 按需执行 `Suggest`、`Reset`、`To HLS`、`Detach`。

结果：你可以把“临时选色”变成“可维护标签体系”，后续批量改色更稳定。

### 4) 用 History 时间线做可逆实验

1. 打开 `History` 面板，查看过去/未来状态。
2. 点击任意状态点直接跳转到该时刻。
3. 用顶栏快捷操作快速来回：
   - `Ctrl/Cmd + Z`：撤销。
   - `Ctrl/Cmd + Shift + Z`：重做。
   - Windows 下也支持 `Ctrl + Y` 重做。

结果：你可以放心做激进尝试，不满意就回到旧状态。

### 5) 用 Saves Manager 管理会话版本

1. 打开 `Saves Manager`。
2. 点 `Save Current` 为当前 Studio 状态命名存档。
3. 需要回档时点 `Load`，确认后加载该存档。
4. 可对手动存档 `Rename`、`Delete`。

说明：列表中的闪电图标为自动保存条目；会按时间排序并显示当前会话。

## 结果预期

- 你可以稳定处理复杂层级，而不是靠反复试错碰运气。
- 你可以把多层属性修改从“逐层点改”升级为“规则化批量改”。
- 你可以建立可复用的配色标签与偏移方案，减少重复劳动。
- 你可以在历史与会话两条线并行兜底，显著降低误操作成本。

## 常见失败与恢复

### 1) 拖了图层但层级没变化

可能原因：

- 目标层被锁定，不允许拖拽。
- 拖放位置没有跨过有效阈值，优先级未改变。

恢复：

1. 先确认目标行不是锁定状态。
2. 把图层明显拖到目标项上方或下方再松手。
3. 到 `Part Inspector` 查看 `Priority` 是否已变化。

### 2) Batch Edit 显示了但改动不生效

可能原因：

- 选中层数量为 0。
- 当前属性不适用于被选图层（常见于颜色）。

恢复：

1. 先用 `Ctrl/Cmd + A` 验证多选链路。
2. 先测试 `Opacity` 或 `Priority`，确认批量通道正常。
3. 颜色批量时改用可着色图层集合。

### 3) 调色板 Tag 修改后结果和预期不一致

可能原因：

- 正在编辑某个 Tag，色盘输入被写回 Tag 而非当前层。
- Advanced 偏移仍在生效。

恢复：

1. 先退出 Tag 编辑模式（Done）。
2. 在 `Advanced` 里 `Reset` 偏移后重新应用。
3. 必要时 `Detach` 成原始色值再继续调整。

### 4) 历史跳转后想回最新状态

可能原因：

- 当前停在过去状态，未来栈仍存在。

恢复：

1. 连续重做直到最新。
2. 或使用历史区的 `Jump Latest` 直接回到当前末端状态。

### 5) 载入存档后发现当前修改丢失

可能原因：

- `Load` 会覆盖当前未保存会话状态。

恢复：

1. 每次大改前先 `Save Current`。
2. 若已覆盖，先查自动保存条目是否包含所需状态。
3. 再配合 `History` 时间线找回最近可用版本。

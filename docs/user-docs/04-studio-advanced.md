# 🚀 Studio 高级 (Studio Advanced)

本章只讲 Studio 的高级进阶能力：图层重排、多选批量编辑、调色标签库、撤销重做、会话管理。

## 🎯 到底能干什么？

- **处理复杂叠穿**：好几件内衣/外套在一起遮挡出现 Bug，你需要强行调换谁在前谁在后。
- **批量“涂装”大工程**：一次性把所有带花边的图层涂成统一的红色，把所有裙子图层透明度统一下调。
- **打造私人配色库**：不想每次都慢慢调那个“神秘特调粉色”了？保存下来当 Tag，甚至做偏色（冷色调粉/暖色调粉）。
- **后悔药中枢**：尝试激进的搭配也不怕，自带时间线跳转。

## ⚡ 核心能力速查手册

### 1) 🛠️ Layers 模式：破除遮挡诅咒
如果你在穿多件衣服时出现了奇怪的“内裤穿在外裤外”等重叠 Bug：
1. 打开界面右侧悬浮靠下的 `Layers` 面板（如果没有，请在顶栏或工具坞呼出）。
2. 在列表里，你身上的每一层都在这。
3. **直接拖拽**：按住要调整的图层往上或往下拖。系统会实时重算 `Priority`（优先级），拯救穿模问题。
> 💡 提示: 同部件同优先级的图层会被打包成一个折叠组，允许你“一组组”直接搬家。

### 2) 🖌️ 批量编辑 (Batch Edit)：彻底告别“点断手”
给十几个图层改同一个参数，会点鼠标点到发麻。
1. 在右侧 `Part Inspector` 切换为 `Multi` 模式。
2. 勾选所有你想改的图层。
3. 此时界面会出现强力工具 `Batch Edit`：
   - **Opacity（透明度）**、**Offset（位移）**、**Priority（层级）**。
   - **Color（颜色）**：直接打开高级调色板，把所有选中图层全部染成目标色。
4. **两种强力修改模式**：
   - `=` 绝对值：全部变成这个数字（“统统给我变 50% 透明度”）。
   - `±` 相对值：在它原来的基础上增减（“在现有的透明度基础上再减 10%”）。

### 3) 🎨 标签体系 (Palette Tags)：告别眼瞎选色
每次捏衣服都靠感觉在这几百万种颜色里去点那个特定的位置？
1. 在工具坞（Tool Dock）打开 `Palette`（调色板）面板。
2. **存入快捷色 (Saved)**：当前选好了一个满意的颜色，点 💾 丢进常用色块里。
3. **晋升为标签 (Tag)**：点 🏷️ 把这串颜色命名成“妖精蓝”保存。以后直接点击这个 Tag 应用，还能看这个 Tag 用在了多少个图层上！
4. **高级黑科技 (Advanced 偏移)**：基于“妖精蓝”，只调 `H/L/S` 滑块，快速生成“稍暗点的妖精蓝”、“稍亮点的妖精蓝”，且统一管理。

### 4) ⏪ 时间旅行 (History)
瞎改衣服改崩了？
1. **快捷键救命**：直接按 `Ctrl/Cmd + Z` (撤销)、`Ctrl/Cmd + Y` (重做)。
2. **面板穿梭**：打开 `History` 面板，里面是一条完整的图文时间轴（“刚调了透明度” -> “然后改了颜色”）。点哪个时间点，小人就立马变回当时的模样。

### 5) 💾 会话存档 (Saves Manager)
这是一套衣服捏了三天还没捏完的救星。
1. 你的每一次动作，闪电图标都会在后台**自动保存 (Auto-save)**，就算断电也不怕。
2. 捏到一个你觉得完美的里程碑，点 `Save Current` 手动存一个命名档“初版结构完成”。
3. 随时通过 `Load` 切回其他存档，把不同的捏衣方案作对比。

## 🚑 急救信箱

### 1. 我拖了 Layers 图层，但前后顺序完全没反应！
**检查**：目标层是不是带了小锁头？或者你在错误的位置松开了鼠标。
**恢复**：明显拖过目标图层上方，观察是否有插入高亮指示线再松开。确认它的 Priority 数字是不是真的变了。

### 2. 批量改颜色没生效？
**检查**：选中的图层是不是不可着色图层？或者选了 0 个图层？
**恢复**：按 `Ctrl/Cmd + A` 确认当前有蓝色的多选边框。如果不确定通道是否通畅，先用 `Opacity` 改个 50% 测一测，再试颜色。

### 3. 我加了调色板 Tag 的 Advanced 偏移结果颜色很怪
**检查**：你的偏移可能加得太猛，或者还在编辑名字模式。
**恢复**：退出名字编辑（点 Done）。在 Advanced 区域点击 `Reset`，或者直接从标签栏重新点击一次主色色块。

### 4. 读了这个存档我的辛勤劳作全没了！
**检查**：这是正常机制，Load 会强制把你覆盖回存档时的样子。
**恢复**：每次做大手术前先点 `Save Current`，万一出事，赶紧看看你的闪电图标自动保存条目，或用 `History` 回跳自救。

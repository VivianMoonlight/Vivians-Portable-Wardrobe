# 故障排查与 FAQ (Troubleshooting & FAQ)

衣服穿不上？界面出 BUG？文件丢了？别慌，对照这份“急救手册”来修。

## 🚑 常见症状与急救措施

### 症状一：鼠标悬停不出预览、点击 Apply 没换衣服
**可能原因**：
1. 这个部位带有 `Original`（强制保留现有）的 Filter 保护规则。
2. 你当前处于游戏内的特定限制状态（比如被严格捆绑，不允许自主更换外观）。
3. 这个装扮文件是个空的，或者包含了游戏里已经删除的非法物品。

**急救方法**：
- **检查 Filter 漏斗**：点开这件衣服的 Filter 按钮，看看它的大基调是不是选错了（尝试改成 `Full replace` 全量替换试试）。
- **取消锁定**：检查是否有手抖把某些部位设置为 `Original` 的过滤规则。
- **环境自检**：脱困后再尝试应用换装。

---

### 症状二：不小心把精心捏好的头型/五官给覆盖没了
**可能原因**：
点击了 `Full replace`（全量覆盖），由于这件目标衣服不包含你现在的专属五官数据，系统强制把你的脸“清零”了（或者变成了衣服原主人的脸）。

**急救方法**：
1. **千万别乱点**，立刻切到底部的 **History (历史记录)** 面板。
2. 找到倒数第二个历史快照（那是有你原来的五官的最新记录）。
3. 鼠标悬停确认有脸后，点击 **Apply**，满血复活！

---

### 症状三：朋友发的 BCX 代码导入失败报错
**可能原因**：
1. 复制漏发了一截代码字符（最常见）。
2. 使用了带有富文本格式的输入框导致代码掺杂了换行或空格。
3. 朋友用了很久以前不支持的版本导出的 BCX。

**急救方法**：
- **重拿代码**：叫朋友用 `Export as BCX` 重新复制一遍，确保头尾一字不差。
- **纯文本粘贴**：直接在网页里 `Ctrl+V` 粘贴进 VPW 的 `Import BCX` 输入框。

---

### 症状四：系统界面红灯闪烁，提示容量超载
**详细解释参考**：👉 [06-sync-and-storage.md](06-sync-and-storage.md)

**急救方法**：
1. 别紧张，**你的衣服没有丢失**！只是云端小网盘被塞爆了。
2. 找到几个你平时不怎么穿、只做存档用的衣服文件夹。
3. 右键文件夹，把云同步开关设为 **Cloud Off**。红灯立马就会变绿。

---

### 症状五：在另一台电脑/手机登录时，找不到新衣服了
**可能原因**：
1. 上一台电脑关机太快，浏览器还没来得及把数据推上云端。
2. 你上一台电脑的云状态是红灯超载，根本挤不上去。
3. 这些衣服所在的文件夹被你设成了 **Cloud Off**。

**急救方法**：
- 最稳妥的办法：如果你有之前的 JSON 全站备份（Export），直接传到新电脑上，点击 **Import** 导进去。
- 确认上一台电脑为绿灯状态，且该文件夹是 **Cloud On**。

## ❓ FAQ (常见问题)

**Q1：VPW 会弄坏我原本在单机/原系统（Player Wardrobe）里的衣服吗？**
A：绝对不会。VPW 采用的是双轨并行技术，它只读取数据但不搞破坏。原版衣柜和 VPW 是两座互不干扰的房子。

**Q2：如果要一键清空重来，有什么办法？**
A：只要把最大的根文件夹“删除”扔进垃圾桶即可。但在做这个危险动作前，**强烈建议你导出一次 JSON 备份包保存好**！

**Q3：可以用这个工具当游戏外挂，强行拔掉别人身上的锁，或者给别人乱穿衣服吗？**
A：不能。VPW 只是外观辅助工具，换装的**最终权限仍然由游戏底层服务端掌控**。如果你没有权限脱那个锁，点了 Apply 也会提示验证失败。

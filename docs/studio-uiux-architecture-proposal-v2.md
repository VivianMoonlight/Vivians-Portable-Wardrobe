# Studio UI/UX 架构提案（V2）
> 角色视角：独立设计架构师  
> 目标：在保留现有专业能力的前提下，显著降低上手门槛与操作负担

---

## 0. 执行摘要

当前 Studio 的核心能力完整、专业深度高，适合中高频用户；但信息密度偏高、并行面板过多、模式切换语义分散，导致新手容易“看得见功能、做不出结果”。

本提案采用“**渐进披露 + 任务导向 + 双速工作流**”框架：
- 新手默认进入简化工作台（只暴露必要面板与动作）。
- 熟练用户可一键切换专业工作台（保留原有并行编辑效率）。
- 通过统一的折叠逻辑和状态机，减少认知跳跃。

---

## 1. 现有方案评估（优缺点）

## 1.1 优点（应保留）

1. **职责分栏清晰**：Preview / Stack / Part / Inspector / Asset 分工明确。  
2. **编辑安全性高**：历史、自动保存、确认机制完善。  
3. **专业操作完整**：Replace/Multi/Move、图层优先级、调色语义管理都具备。  
4. **反馈体系较健全**：状态 Chip、保存状态、恢复提示可感知。

## 1.2 主要问题（上手门槛来源）

1. **首屏并发信息过多**：同屏面板多，用户难判断“第一步做什么”。  
2. **模式语义分散**：View/Move、Single/Multi、Replace 在不同区域触发，心智路径断裂。  
3. **折叠逻辑不统一**：不同面板有各自折叠规则，用户难预期“展开后会发生什么”。  
4. **工作流缺少显式引导**：从选栈到替换到精修虽可行，但缺少“任务路径”表达。  
5. **移动端切换成本高**：Tab 切换存在，但任务上下文连续性弱。

---

## 2. 设计框架（借鉴设计类 Web 应用的共性模式）

不复制具体产品形态，提炼共性：

- **中心画布优先**：视觉结果永远是主舞台。  
- **左侧结构、右侧属性**：左边管理对象，右边编辑当前上下文。  
- **面板可叠、上下文唯一**：右侧同一时刻只强调一个“当前任务面板”。  
- **新手路径可预设**：通过向导/步骤条先完成“最小可用结果”。

据此形成本项目的三层架构：

1. **任务层（Task Layer）**：我现在在做哪一步（选栈 / 换件 / 精修 / 导出）。  
2. **结构层（Structure Layer）**：当前操作对象是谁（Stack / Part / Layer）。  
3. **属性层（Property Layer）**：当前对象怎么改（Inspector / Asset / Palette）。

---

## 3. 新布局方案（Easy + Pro 双工作台）

## 3.1 默认：Easy Workspace（新手优先）

### 桌面布局
- **左 240px（结构栏）**：`StackList + PartList`（上下分区，可拖拽分割）。
- **中间自适应（主舞台）**：`PreviewWidget`（固定核心可见）。
- **右 320px（上下文栏）**：单容器切换 `Inspector / Asset / Palette`（同一时刻仅显示一个主面板）。
- **底部 36px（时间条）**：`History` 迷你条（仅 Undo/Redo/跳点入口）。

### 价值
- 首屏只看见“结构 + 画布 + 当前编辑”，降低首次决策成本。

## 3.2 进阶：Pro Workspace（专家效率）

- 在 Easy 基础上开启可选抽屉：`LayerManager / Full History / Saves`。  
- 支持多面板并行，但遵循统一折叠规则（见第 4 节）。  
- 提供“工作区预设”：`Asset Editing`、`Color Session`、`Layer Tuning`。

## 3.3 移动端布局

- 顶部保持画布；底部使用 4-tab：`结构`、`替换`、`属性`、`历史`。  
- `Palette/Saves` 进入二级抽屉，而非同级主 Tab。  
- 始终显示“当前任务步骤条”（简版），确保上下文不断裂。

---

## 4. 面板折叠与显示状态机（统一规则）

## 4.1 三态模型（所有侧栏统一）

- **Pinned（固定）**：常驻显示，参与布局。  
- **Peek（临时）**：悬停/快捷键呼出，失焦自动收回。  
- **Hidden（隐藏）**：不占空间，仅在面板管理器中可见。

## 4.2 右侧上下文栏规则

1. 右栏同一时刻只允许一个主面板为 `Pinned`（Inspector/Asset/Palette 三选一）。  
2. 触发 Replace 时自动切换到 `Asset`，应用后回到 `Inspector`。  
3. 颜色编辑进入时临时 `Peek Palette`，完成后回到来源面板。  
4. 用户手动 Pin 的面板具备最高优先级，不被自动切走（仅弹出提示）。

## 4.3 折叠默认策略

- **首次打开项目**：
  - 展开：`Preview`、`StackList`、`PartList(当前组)`、`Inspector(核心属性)`
  - 收起：高级属性、LayerManager、Saves、完整 History
- **按任务展开**：
  - Replace 流程：自动展开 `Asset` + 当前槽位信息
  - Multi 流程：自动展开批量字段，折叠单体细节
  - Move 流程：显示位置相关字段，隐藏颜色字段

---

## 5. 工作流重构（从“功能驱动”改为“任务驱动”）

## 5.1 四阶段主流程

1. **Assemble（组装）**：选栈、选部件、补空槽。  
2. **Replace（替换）**：预览候选、应用资产。  
3. **Polish（精修）**：颜色、位移、图层优先级。  
4. **Commit（提交）**：保存、应用到角色、导出。

每阶段仅暴露该阶段的主按钮和相关面板，其他功能进入“更多”抽屉。

## 5.2 新手引导路径（首次 3 分钟）

- Step 1：选择或创建 Stack。  
- Step 2：选择一个 Part（或空槽）。  
- Step 3：在 Asset 中点击应用。  
- Step 4：在 Inspector 调整 1~2 个核心参数。  
- Step 5：点击保存并完成。

该路径完成后再提示高级能力（多选、图层、调色标签、存档管理）。

## 5.3 专家快捷路径

- `Cmd/Ctrl + K` 打开命令面板（跳转任务、切换面板、执行导入导出）。  
- 键盘为一等公民：批量选择、模式切换、历史跳转全部可快捷操作。  
- 支持“保持当前任务上下文”的面板记忆（按 Stack 维度记忆）。

---

## 6. 关键交互规范（建议）

## 6.1 操作反馈分级

- **微反馈（<300ms）**：字段保存成功、参数已应用。  
- **中反馈（任务级）**：Replace 应用成功、批量修改已完成。  
- **高风险反馈**：删除/覆盖/清空需二次确认，支持撤销入口。

## 6.2 误操作防护

- 危险操作默认“延时确认（armed）+ 撤销 Toast”。  
- 自动保存失败时，右上角固定告警，直到恢复。  
- Replace 连续点击采用节流与队列，避免状态错乱。

## 6.3 可发现性增强

- 所有 icon-only 按钮在首周使用期显示轻量文字标签（可关闭）。  
- 复杂模式切换（Single/Multi、View/Move）保留状态说明句。  
- 面板首次出现时显示 1 次“我能做什么”提示。

## 8. 落地路线图（建议 3 阶段）

## Phase A：可用性降噪（1~2 周）
- 引入 Easy Workspace 默认布局。  
- 统一右侧上下文栏为单主面板模型。  
- 建立统一折叠三态（Pinned/Peek/Hidden）。

## Phase B：任务化流程（1~2 周）
- 增加四阶段任务条（Assemble/Replace/Polish/Commit）。  
- 首次引导（3~5 步）与完成后高级能力解锁提示。  
- Replace→Inspector 自动回流策略。

## Phase C：专家效率增强（1~2 周）
- 命令面板与工作区预设。  
- 面板记忆（按 Stack 维度）。  
- 历史/存档联动视图优化。

---

## 9. 评估指标（用于验证改造是否成功）

建议上线后跟踪以下指标：

1. **首个有效编辑完成时间**（首次打开到成功替换并保存）。  
2. **错误回退率**（Replace 后立即 Undo 的比例）。  
3. **任务完成率**（Assemble→Commit 完整闭环比例）。  
4. **面板切换频次**（每分钟切换次数，越低越聚焦）。  
5. **新手 7 日留存操作深度**（是否进入高级功能）。

---

## 10. 结论

你的现有 Studio 已具备“专业编辑器”的骨架，问题不在能力缺失，而在能力呈现顺序。  
V2 方案核心不是“增加功能”，而是通过 **默认简化、任务分层、统一折叠状态机**，让用户先完成、再精通。  
这会同时提升两类体验：新手更快出结果，专家仍保留高天花板。
